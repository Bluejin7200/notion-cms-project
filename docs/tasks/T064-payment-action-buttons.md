# T064: 상세 페이지에 상태별 처리 버튼과 승인·지급완료 확인창을 추가

> Phase 4 | 관련 기능: F003, F004 | 선행 작업: T035, T062 | 크기: M | 상태: 대기

## 명세
- PRD 상세: 현재 상태에 허용된 처리 버튼만 노출 — 요청: 승인·반려, 승인: 지급완료·반려, 지급완료·반려·알 수 없음: 버튼 없이 읽기 전용.
- 모든 처리 전 확인창, 처리 중 버튼 비활성화, 처리 후 상태·처리일 갱신 표시, 성공/실패 토스트.
- 이 작업은 승인·지급완료 확인창과 버튼 영역. 반려 버튼은 자리만 두고 다이얼로그는 T066.
- 요청 본문에 현재 상세의 `lastEditedTime`을 넣는다 (F003 동시성).

## 관련 파일
- 생성: `src/components/payments/payment-actions.tsx`
- 수정: `src/components/payments/payment-detail.tsx`
- 참고: `src/components/common/confirm-dialog.tsx`, `src/lib/payments/transitions.ts`(T010), `src/hooks/use-update-payment-status.ts`(T062)

## 구현 단계
- [ ] 1. `PaymentActions({ detail })`: `getAllowedActions(detail.status)`로 버튼 목록 계산
- [ ] 2. 버튼 없음 → 안내 문구: 최종 상태 "처리가 끝난 건입니다. 정정은 Notion에서 직접 수정하세요." / unknown "상태 값을 알 수 없어 처리할 수 없습니다. Notion의 상태 옵션을 확인하세요."
- [ ] 3. 승인·지급완료: `ConfirmDialog`("이 지급 요청을 승인할까요?", 금액·수령처 요약 표시) → 확인 시 `mutate({ action, lastEditedTime: detail.lastEditedTime })`
- [ ] 4. `isPending` 동안 모든 처리 버튼·확인 버튼 비활성화, 성공 시 다이얼로그 닫힘
- [ ] 5. 반려 버튼: T066 연결 전까지 비활성 상태로 두지 않고, T066과 같은 Phase 안에서 연결 (이 작업 완료 시점엔 버튼 숨김)
- [ ] 6. 모바일: 버튼 전체 폭 세로 배치

## 완료 기준

- [ ] 승인 확인 후 상태 배지 "승인"·처리일 KST 오늘이 새로고침 없이 표시
- [ ] 처리 중 버튼 `disabled`
